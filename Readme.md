## Overview

OWO Auto Coinflip Bot is a Python-based automation project designed to automate Coinflip interactions in an OWO Discord channel.

Follow the setup instructions below to configure and run the project.

## Requirements

Before getting started, make sure you have:

- Python 3 installed
- Git installed
- An IDE or code editor
- Required Python dependencies

## Installation

**1. Clone the Repository**

```bash
git clone YOUR_REPOSITORY_URL
```

Alternatively, download the repository as a ZIP file and extract it.

**2. Navigate to the Project Directory**

```bash
cd OWO-Auto-Coinflip-Bot
```

**3. Install Dependencies**

```bash
pip install -r requirements.txt
```

## Configuration

Create a `.env` file in the root directory of the project.

Add the following environment variables:

```env
DISCORD_TOKEN=your_discord_token
CHANNEL_ID=your_channel_id
```

Replace the placeholder values with your configuration.

**Important:** Never share or upload your Discord authentication credentials. Keep your `.env` file private and add it to `.gitignore`.

## Running the Project

Once the dependencies and configuration are ready, run:

```bash
python3 main.py
```

Make sure you're running the command from the correct project directory.
